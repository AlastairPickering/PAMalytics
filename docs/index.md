# PAMalytics

An open source, no-code, classifier-agnostic, interactive dashboard to efficiently review bioacoustic classifier results. :contentReference[oaicite:1]{index=1}

## What it does

PAMalytics lets you:
- summarise detections across recorders and time
- validate and correct detections quickly using spectrograms + audio
- keep the original classifier output intact while storing your edits
- export a validated CSV ready for downstream analysis :contentReference[oaicite:2]{index=2}
